# 消息标识与模块测试入口

版本：0.5.1。日期：2026-10-29。

界面和服务提示通过固定消息标识取译文，不再根据中文字符串、前后缀或正则猜测含义。修改中文文案只需修改词条内容；调用处的标识和英文译文不受影响。

| 模块 | 职责 |
| --- | --- |
| `public/messages.js` | 界面文案的中英文词条 |
| `public/system-messages.js` | 服务状态、日志和错误的中英文词条 |
| `public/message.js` | 构造、校验、格式化及限制消息参数；生成兼容的活动、日志和错误字段 |
| `public/i18n.js` | 当前语言、显式静态标记、表单错误与语言切换 |
| `public/api-client.js` | 将 HTTP 错误的消息标识保留到界面错误对象 |

## 字段与兼容

消息采用 `{ id, params }`。例如 `message('error.setting_range', { name: 'maxWakeSends', min: 1, max: 100 })`。参数只能包含声明的名称，值可以是文本、有限数字、布尔值、null 或有深度限制的嵌套消息。用户提供的名称、备注、输出和错误详情作为参数时保持原文。

现有文本字段继续保留中文文本，供旧调用方和直接检查数据使用；新增可选字段负责翻译：

| 数据 | 文本字段 | 消息字段 |
| --- | --- | --- |
| 任务活动 | `activity` | `activityMessage` |
| 日志、连接、存储状态 | `message` | `messageInfo` |
| HTTP 错误 | `error` | `errorInfo` |
| 精简列表提示 | `summaryNotice` | `summaryNoticeInfo` |

标识和参数随任务和日志一起保存。列表摘要限制消息参数长度，完整详情仍走原有接口；消息字段变化会更新详情修订号。内部错误继续通过 HTTP 错误策略隐藏，只有允许的提示和参数能够返回客户端。

旧数据、未知标识及外部诊断没有有效消息标识时显示原文，不根据中文反推类别。新模型输出替换系统活动时会清除旧消息字段，避免套用上一次活动的译文。语言切换不会改写任务名称、备注、自定义续作消息或模型输出，也不会重新发送消息。

静态 HTML 使用 `data-i18n` 和 `data-i18n-title`、`data-i18n-aria-label`、`data-i18n-placeholder` 标记。动态组件直接调用 `t(id, params)`；组件中的 HTML 结构不进入翻译词条。

## 测试入口

`mountPage(environment)`、`mountWidget(environment)` 接收 DOM、时间、请求和消息源，浏览器加载时仍自动挂载。测试直接导入并调用相同入口。`discardLegacyAccess()` 独立处理旧凭据清理；`desktop/runtime.cjs` 的 `createDesktopRuntime()` 明确接收原生依赖、运行环境、计时器和已有窗口，由 `desktop/main.cjs` 负责启动。

页面、访问清理、桌面布局以及真实窗口展开测试均不再读取、改写或拼接生产 JavaScript 来暴露私有函数。原生窗口验收继续使用真实 Electron 几何计算；测试窗口和数据独立，沙箱保持开启。

`tests/message-contracts.test.js` 覆盖词条参数一致性、中文文案变化、用户文本保留、无效消息、嵌套参数限制、HTTP 错误往返、显式静态标记、真实存储重启、摘要限制和详情修订。现有语言测试和回复检查测试改为检查消息契约及实际运行结果。

固定源码验证目录：`.cache/message-contract-refactor-0.5.1/`。双语界面验收报告与截图：`.cache/message-contract-ui-qa-0.5.1/`。本轮只保存源码和本地提交。
