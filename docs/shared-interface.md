# 完整页面与挂件的共享界面

版本：0.5.1。日期：2026-10-29。

完整页面和挂件继续使用各自的布局、导航和窗口交互。请求策略、任务状态与操作判断、任务内容和工作表单集中在共享模块中维护。

| 模块 | 职责 |
| --- | --- |
| `public/api-client.js` | 创建 JSON 请求客户端；统一凭据策略、重定向限制、写请求标记、服务错误和 35 秒超时 |
| `public/task-view.js` | 任务状态文字、暂停或继续按钮、结束操作条件、进度值；两种布局的卡片和详情，以及共用的备注、续作消息和输出内容 |
| `public/task-forms.js` | 新建工作与导入监测表单；共用字段、限制和提示，保留布局、目录选择和按钮样式的差异 |
| `public/html.js` | 统一转义用户文本与属性值 |
| `public/icons.js` | 现有 SVG 图标集合 |
| `public/app.js`、`public/widget.js` | 页面和窗口生命周期、局部布局、事件处理，以及调用共享组件 |

任务卡片和详情通过 `taskPresentation()` 取得当前语言的状态、操作和进度信息。共用的业务内容只定义一次，布局差异由独立的小模板表达。模板按内容段落展开，页面事件处理不再嵌入完整的新建或导入表单。

两种界面都在完整详情加载后才允许编辑续作消息；运行、启动、授权和暂停中的工作隐藏结束按钮，继续通过暂停流程停止。监测详情展示备注和消息，工作详情展示计划和输出。用户标题、备注、消息、计划和输出始终按原文转义后显示。

请求客户端由各界面创建，详情缓存和窗口状态仍分别持有。两处都使用既有的 `credentials: omit`、`redirect: error` 和写请求标记；完整页面补齐挂件已有的 35 秒超时。实时流仍由 `VisibleFeed` 管理，隐藏视图订阅和动画的生命周期继续独立维护。

## 验证方式

- `tests/shared-ui.test.js` 检查请求与错误处理、超时、两种布局的状态和操作一致性、转义、表单字段，以及实际页面脚本中的创建、导入和消息编辑提交。
- `tests/mode-views.test.js` 通过页面和挂件入口检查卡片、详情及设置，移除对生产函数源码形状的截取。
- `tests/fixtures/widget-view.js` 使用同一套模拟 DOM、请求与事件环境加载两种页面脚本；测试不启动真实任务或发送聊天消息。
- HTTP 集成检查遍历页面模块的实际导入，确认所有共享模块均包含在静态资源白名单中。

固定源码回归目录为 `.cache/shared-ui-refactor-0.5.1/`。运行数据和界面验收数据使用独立目录；本轮未构建或安装新版本。
